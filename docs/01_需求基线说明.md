# PaperSeek 需求基线说明（W1 冻结）

> 依据：《PaperSeek 软件需求规格说明书与系统概要设计 V1.0》（`产品设计.docx`，PS-SRS-001）
> 本文件把产品设计文档压缩成可执行基线，并记录 W1 需求评审做出的决策。
> 后续需求变化一律走 `docs/03_修改记录.md` 的变更流程。

## 1. 一句话目标

构建**可离线运行**的科研文献智能语义检索原型：对公开基准 SciFact 做可复现的多算法检索评价，
并支持在本地 PDF 论文库中检索、定位到原文片段与页码。

## 2. 用户与场景

| 角色 | 核心诉求 |
| --- | --- |
| 高校学生/科研人员 | 用自然语言问题找相关论文，看到标题、摘要片段、得分 |
| 任课教师 | 算法实现真实、指标可复现、能对比多种检索器 |
| 开发维护者 | 模块可测试、索引可重建、数据可复现下载 |

## 3. 范围基线

**P0（课程验收必须完成）**：FR-01 ~ FR-11

| 编号 | 功能 | 本项目实现方式 |
| --- | --- | --- |
| FR-01 | SciFact 数据读取 | `paperseek.data.scifact`，BEIR 官方 zip |
| FR-02 | 文本规范化 | `paperseek.preprocessing.text`，TF-IDF/BM25 共用 |
| FR-03 | TF-IDF 检索 | `TfidfRetriever`（sklearn 向量化 + 余弦） |
| FR-04 | BM25 检索 | `BM25Retriever`（自实现 Okapi BM25，记录 k1/b） |
| FR-05 | SBERT 语义检索 | `SBERTRetriever`（all-MiniLM-L6-v2） |
| FR-06 | 统一检索接口 | `BaseRetriever` + `SearchResult` |
| FR-07 | 自然语言查询 | `SearchService.search`，空查询报错 |
| FR-08 | 算法切换 | Streamlit 选择框 → 真实调用对应检索器 |
| FR-09 | 公开基准评价 | `evaluation.metrics` + `evaluate_retriever`，Recall@10/MRR@10/NDCG@10 |
| FR-10 | 结果导出与图表 | `metrics.csv` / `per_query.csv` / `latency.csv` + 4 张图 |
| FR-11 | 本地 Web 界面 | Streamlit 四页面 |

**P1（尽力完成）**：FR-12 PDF 导入、FR-13 片段检索、FR-14 RRF 融合、FR-15 索引缓存、
FR-16 检索解释信息。

**P2（明确不做/仅说明）**：FR-17 跨语言检索（作为展望与演示设想）、FR-18 大规模向量索引（讨论 ANN 方案）。

## 4. W1 评审决策（对应 SRS 10.1 待确认事项）

| 编号 | 问题 | 决策 | 依据 |
| --- | --- | --- | --- |
| PD-01 | 仓库公开性 | GitHub **公开**仓库 `wangkangcoder/paperseek-nlp` | 用户 2026-10-19 确认 |
| PD-02 | 工期 | 按 SRS 6 周计划推进，P0 全做、P1 尽力 | 用户 2026-10-19 确认 |
| PD-03 | PDF 是否升级 P0 | 保持 P1（不要求现场上传自己的论文） | PD-02 同批确认 |
| PD-04 | 领域演示语料 | 优先按时频分析主题收集 arXiv 开放论文；若下载受限，改用 NLP/IR 主题并登记变更 | SRS 6.3 + 可获取性 |
| PD-05 | 跨语言检索 | 不纳入量化评价，仅作为展望/演示设想 | SRS 1.3 / 6.2 |
| PD-06 | 单一标注者 | 领域查询的中文相关性标注由项目作者完成，报告披露主观性局限 | SRS 6.3 |

## 5. 关键质量目标

| 编号 | 目标 | 验证方式 |
| --- | --- | --- |
| NFR-01 | 缓存后单查询 P95 ≤ 3s（CPU 或 GPU 需注明） | `latency.csv` |
| NFR-02 | 返回的 doc_id 全部存在于语料；按分数降序 | 单元测试 + 实验脚本断言 |
| NFR-03 | 固定数据版本、模型、参数、随机种子 | `config.json` + `IndexManifest` |
| NFR-04 | 空输入/损坏 PDF/缺索引/模型失败有中文提示 | 界面与异常测试 |
| NFR-05 | 数据隐私：PDF 只存本地，不调用在线大模型 | 代码审查 |
| NFR-06 | 模块分离、关键功能有测试 | pytest + 覆盖率说明 |
| NFR-08 | 索引与语料/模型版本绑定 | `IndexManifest.verify` + 测试 |
| NFR-09 | 16GB 内存单机可跑 | MiniLM + 摘要级语料 |

RRF 倒数排名融合 / SBERT 句向量模型 / P0-P2 优先级。
