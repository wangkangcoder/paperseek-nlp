## 2. 冻结数据结构（`paperseek.schemas`）

| 结构 | 关键字段 | 说明 |
| --- | --- | --- |
| `Document` | `doc_id, title, text, source, path, metadata` | 文献级检索单位；PDF 场景下 `doc_id` 是片段 ID，父文献/页码在 `metadata` |
| `Chunk` | `chunk_id, doc_id, page, text, title, path` | PDF 片段；`to_document()` 转统一 `Document` |
| `Query` | `query_id, text, language` | 标准实验查询或用户临时查询 |
| `SearchResult` | `doc_id, rank, score, title, snippet, source, chunk_id, page, path` | 统一检索输出；`rank` 从 1 开始 |
| `IndexManifest` | `retriever, corpus_hash, n_documents, params, model_id, corpus_name, created_at` | 索引版本清单；`verify(corpus_hash)` 不匹配抛 `ManifestMismatchError` |
| `Qrels` | `Dict[query_id, Dict[doc_id, int]]` | 相关性等级 0/1/2，只来自人工标注 |

**禁止修改字段名/含义**。确需扩展只能在 `metadata` 中加键，并写入变更记录。

## 3. 检索器契约（`paperseek.retrievers.base.BaseRetriever`）

```python
class MyRetriever(BaseRetriever):
    name = "myretriever"                      # 必须与注册名一致

    def build_index(self, documents, config=None) -> IndexManifest: ...
    def search(self, query: str, top_k: int = 10) -> list[SearchResult]: ...
    def save(self, directory: Path) -> None: ...
    @classmethod
    def load(cls, directory: Path) -> "MyRetriever": ...
    def params(self) -> dict: ...             # 返回可复现参数
```

必须满足：

1. `build_index`：
   - 调用 `self._set_documents(documents)` 保存语料（基类会校验重复 ID）；
   - 用 `corpus_hash = compute_corpus_hash(documents)`（`paperseek.index.store`）生成
     `self._make_manifest(corpus_hash, corpus_name, model_id=..., config=config)` 并返回；
   - `model_id`：稀疏检索器为 `None`；语义检索器为实际模型名（如 `all-MiniLM-L6-v2`）。
2. `search`：`query = self._clean_query(query)`；`self._require_ready()`；`top_k = self._normalize_top_k(top_k)`；
   返回 `self._build_results([(doc_id, score), ...])`，按得分降序。空查询抛 `EmptyQueryError`。
3. `save`：写入 `directory / "manifest.json"`（`manifest.to_dict()`）+ 自己的索引文件；
   `RRFRetriever` 还需保存两个子检索器目录。
4. `load`：`paperseek.index.read_retriever_manifest(directory)` 读清单，恢复状态并 `self._manifest = manifest`；
   文件缺失抛 `IndexNotBuiltError`；语料文档从 `documents.jsonl` 恢复可参考
   `paperseek.index.read_documents(directory.parent / "documents.jsonl")`（语料文档库由 Lead 统一保存）。
5. 得分语义：只表示相对排序，界面不得称为“概率”（SRS 7.2）。

> 说明：语料文档库 `data/index/<scope>/documents.jsonl` 由 `scripts/build_index.py` 统一写入，
> 检索器目录内的 `manifest.json` 只保存索引自身与参数；`load` 时不要依赖同目录之外的路径。

## 4. 数据层契约（数据组）

```python
# paperseek/data/scifact.py
@dataclass
class ScifactData:
    documents: list[Document]
    queries: list[Query]          # queries.jsonl 全部查询
    qrels: Qrels                  # 指定 split 的标注
    split: str

def load_corpus(data_dir: Path = config.SCIFACT_DIR) -> list[Document]
def load_queries(data_dir: Path = config.SCIFACT_DIR) -> list[Query]
def load_qrels(data_dir: Path = config.SCIFACT_DIR, split: str = "test") -> Qrels
def load_scifact(data_dir: Path = config.SCIFACT_DIR, split: str = "test") -> ScifactData
```

- BEIR 文件映射：`corpus.jsonl` 的 `_id -> doc_id`、`title`、`text`（可拼接 title 与 text？**保持 `text` 原样**，
  语义组编码时自行决定 `title + text`）；`queries.jsonl` 的 `_id -> query_id`、`text`；
  `qrels/<split>.tsv` 用 `csv.DictReader(delimiter="\t")`，列名 `query-id, corpus-id, score`。
- 校验：ID 或 text 为空、重复 ID、文件缺失 → `DataFormatError`，错误信息包含文件路径与行号。
- 统一入口 `load_scifact` 必须能被 `scripts/build_index.py`、`scripts/run_evaluation.py` 直接调用。

```python
# paperseek/preprocessing/text.py
def normalize_text(text: str) -> str                  # 去 HTML 标签/控制符、压缩空白、小写
def tokenize(text: str, for_bm25: bool = True) -> list[str]   # 分词 + 停用词 + 词干
STOPWORDS: frozenset[str]
```
- TF-IDF 与 BM25 **必须共用** `normalize_text` + `tokenize`（FR-02），保证对照公平。
- 英文语料：小写、按非字母数字切分、去停用词、轻量词干（如去掉复数/ed/ing 的规则或 Porter 简版）。
- 中文（P2/扩展）：`jieba` 可选，不得让 SciFact 流程依赖中文分词结果。

## 5. 语义检索与评价契约（语义组）

```python
# paperseek/retrievers/sbert.py
class SBERTRetriever(BaseRetriever):
    name = "sbert"
    # config: {"model_name": str = config.DEFAULT_SBERT_MODEL, "batch_size": int = 64}
```
- 文档编码文本：`f"{title}. {text}"`（须在 docstring 写明）；查询编码 `query`；
  `SentenceTransformer(..., device=自动选择)`；`normalize_embeddings=True`；相似度 = 点积（等价余弦）。
- `save`：`manifest.json` + `embeddings.npy`（float32）+ `doc_ids.json`。
- `load`：用 `manifest.model_id` 加载同一模型，加载前调用 `config.configure_hf_mirror()`；
  模型与向量维度不一致要报错。
- 缺失 `sentence_transformers` 时模块导入抛 ImportError（注册表会跳过）；测试用 `pytest.importorskip`。
- 内存提示：SciFact 约 5.2k 篇摘要，MiniLM(384维) 编码后约 8MB，可整库驻留。

```python
# paperseek/retrievers/hybrid.py
class RRFRetriever(BaseRetriever):
    name = "rrf"
    # config: {"components": ("bm25", "sbert"), "k": 60, "depth": 100, "model_name": ...}
```
- 内部构建并持有 `BM25Retriever` 与 `SBERTRetriever`；`search` 分别取 `depth` 个结果，
  按 `score(d) = Σ_i 1 / (k + rank_i(d))` 融合，返回 `top_k`。
- `save`：`directory/bm25/`、`directory/sbert/` 两个子目录 + 本层 `manifest.json`；
  `manifest.model_id` = 子 SBERT 模型名（供 SearchService 校验语料版本）。
- 只融合出现在两路结果中的文献吗？**不**：单路出现也计分（标准 RRF），但必须在 docstring 说明。

```python
# paperseek/evaluation/metrics.py
def recall_at_k(ranked: Sequence[str], relevant: set[str], k: int) -> float
def precision_at_k(ranked: Sequence[str], relevant: set[str], k: int) -> float
def mrr_at_k(ranked: Sequence[str], relevant: set[str], k: int) -> float
def ndcg_at_k(ranked: Sequence[str], graded: Mapping[str, int], k: int) -> float
def evaluate_run(ranked: Mapping[str, list[str]], qrels: Qrels, cutoffs=(5,10),
                 relevance_threshold: int = 1) -> dict[str, float]
```
- NDCG：`DCG = Σ (2^rel - 1) / log2(i+2)`，`i` 从 0 开始；IDCG 用理想排序；无相关文档时该查询 NDCG=0。
- Recall@K 分母 = 该查询相关文档总数（可超过 K）。
- 指标名格式：`recall@10`、`precision@5`、`mrr@10`、`ndcg@10`（小写）。
- 必须用 sklearn 的 `ndcg_score` 或手算样例做交叉验证（tests）。

```python
# paperseek/evaluation/evaluator.py

class EvalResult:
```
