# PaperSeek 修改记录（Change Log）

> 本文件与 git 提交历史、里程碑 tag 共同构成变更审计链。
> 每次有实质修改都必须新增一条记录；记录内容必须与提交信息、`docs/02_进度文档.md` 保持一致。
> 修改记录编号规则：`CHG-序号`；项目版本遵循语义化版本 `v主.次.修订`。

## 1. 变更流程

1. 提出变更：写清 **原因、影响范围、优先级变化、预计工作量**（对应 SRS 10.2）。
2. 记录：在本文件登记 `CHG-xxx`，状态 `待实施`。
3. 实施：在分支 `dev` 上完成，提交信息格式 `type(scope): 摘要 [CHG-xxx]`。
4. 验证：跑相关测试并记录证据（命令 + 结果）；Lead 复核。
5. 归档：Lead 提交并打 tag（如 `v0.2.0-w2`）；更新状态为 `已完成` 并填写回退点。

**变更类型**：`需求` / `设计` / `代码` / `数据` / `实验` / `文档` / `环境` / `修复`
**回退方式**：`git checkout <tag>` 或 `python tools/rollback.py restore <tag>`
